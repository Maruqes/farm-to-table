## Build
- Dependencies: `multer`, `@aws-sdk/client-s3` (`forcePathStyle: true`, endpoint and credentials from `config/env.ts`).
- `lib/storage.ts`: `putObject`, `getObject`, `deleteObject`, `ping` (used by BE-21). Nothing else talks to S3.
- `POST /api/products/:id/image` as CT-13 (owner only, field `image`).
- `GET /api/products/:id/image` (public): streams the object with its content type and `Cache-Control`. The bucket stays private. `imageUrl` in every product response becomes `/api/products/<id>/image?v=<updatedAt ms>`. Add this endpoint to ENDPOINTS.md (README gap 8).

## Server rules
- multer memory storage, `limits: { fileSize: 5 MB, files: 1 }`. Over the limit or no file → 400 `fields.image`.
- Decide the type from the file's **magic bytes** (JPEG, PNG, WebP), not from the client's MIME type or file name. Anything else → 400.
- The object key is generated by the server (`products/<id>/<random>.<ext>`); the original file name is never used in a key or path.
- Check ownership before reading the upload body is not possible with multer, so check it right after and discard the buffer on 403/404.
- Replacing an image deletes the old object. Deleting a product (BE-06) deletes its object: add that one call there.
