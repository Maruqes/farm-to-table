# Farm to Table ("Do Campo à Mesa")

Marketplace for local producers with real-time auctions (IPVC-ESTG university project).

```bash
cp .env.example .env     # the only env file: fill BACKOFFICE_APP_KEY and S3_*
make dev
```

- Web http://localhost:5173 · API http://localhost:3000/api/health · Backoffice http://localhost:8081
